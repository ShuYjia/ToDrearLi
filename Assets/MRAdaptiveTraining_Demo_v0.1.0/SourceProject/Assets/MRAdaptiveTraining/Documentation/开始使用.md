# MR 教学智能评价与自适应训练演示包

版本：0.1.0。目标编辑器：Unity 2021.3.29f1c1。接收方设备：PICO 4U。

本包提供单人、本地、规则驱动的演示闭环。包含独立模拟任务、评价与重复训练控制、中文教师面板、JSON 记录和 CSV 导出。默认规则仅用于演示，未经真实教学数据验证。

## 五分钟运行演示

1. 建议先在目标工程副本或同版本空项目中导入 `MRAdaptiveTraining_Demo_v0.1.0.unitypackage`。
2. 等待 Unity 编译完成。所有资产位于 `Assets/MRAdaptiveTraining`，不会替换原场景或项目设置。
3. 选择菜单 `Tools > MR 教学 > 打开独立演示场景`。如当前场景有修改，先保存。
4. 在 Game 窗口选择接近 1280×900 的大小，点击 Play。
5. 点击“开始新训练”，依次点击“领取工具、安装部件、确认结果”，再提交结果。
6. 查看状态和判断依据，点击“执行安排”。完成后下方教师面板会出现记录。

这是电脑端鼠标操作的演示界面。无需 PICO SDK、网络服务、模型密钥、TextMeshPro 或其他第三方依赖。它不是已经适配头显射线的 VR 面板。

如果只能接收源码：将交付目录 `SourceProject/Assets/MRAdaptiveTraining` 连同 `.meta` 文件完整复制到目标工程的 Assets 下。和导入 unitypackage 二选一，不要复制两份。

## 四条演示路线

| 路线 | 每次操作 | 预期结果 |
|---|---|---|
| 掌握较好 | 连续两次全部按正确顺序完成 | 第一次基本掌握；第二次掌握较好，训练从原计划 3 次减到 2 次 |
| 基本掌握 | 每次先误点一次“安装部件”，再按顺序完成 | 每次记录 1 个错误，保持原计划 3 次 |
| 需要加强 | 每次先误点两次“安装部件”，再按顺序完成 | 前 3 次后继续补练，最多共 5 次；仍未改善则等待教师处理 |
| 数据不可靠 | 点击“报告交互异常”，再完成步骤 | 显示待核实；不因交互问题判为能力不足，不自动减少训练 |

故意不完成三个步骤就提交，可以验证“必要步骤不能跳过”。超过总尝试上限会等待教师处理。演示中改变学生标识并开启新训练，可以展示多名学生的本地汇总，不需要多人联网。

## 记录在哪里

教师面板底部显示实际路径。

- 演示记录：`Application.persistentDataPath/MRAdaptiveTraining/DemoRecords`。
- 正式接入记录：`Application.persistentDataPath/MRAdaptiveTraining/Records`。
- 每次提交保存一个 JSON 文件，包含学生、任务、训练、尝试标识、UTC 时间、时长、错误代码、交互问题、规则快照、判断依据和后续安排。
- CSV 导出到同一目录，UTF-8 BOM 编码，供常用表格软件查看。它是完整记录导出，不受界面筛选影响。
- 写入失败时阻止执行训练调整，并允许重试保存。损坏的 JSON 不会被悄悄统计为有效数据；面板会显示跳过的文件数量。
- 数据只有本机保存和汇总，没有账户登录、服务器、跨头显同步或班级自动分组。

PICO/Android 上的文件通常位于应用私有持久化目录；以设备实际显示的路径为准。教师在 PC 上不会自动看到头显记录；正式演示前需要明确通过设备文件工具取出记录，或另行实现上传接口。

## 交付边界

已提供：规则核心、单人任务适配入口、独立演示场景和预制体、可修改的任务规则资产、教师面板、过程结果日志、CSV、中文接入文档。

待原工程接入：真实任务事件、完整重置、后续教学切换、必要步骤的真实性检查、实际学生标识、PICO 世界空间 UI 与射线交互、Android 真机测试。

本版不包含：多人同步、云端教师平台、机器学习模型、大模型问答、正式评分效度证明。训练时长仅记录，不单独参与学习状态判断。

规则中的稳定性按“当前这轮训练内连续可靠尝试”判断；历史训练保留供教师查看，但不会自动降低下一轮的起始训练量。

## 人工检查

- 中文是否正确显示。演示使用操作系统字体；PICO UI 请使用原工程已有的中文字体资源。
- 按四条路线各跑一次，检查实际尝试次数和教师结果。
- 退出 Play 再进入，刷新记录，确认已完成尝试仍存在。
- 换学生、换任务规则后检查身份归属和统计。
- 真实任务重置后，模型、抓取、碰撞、步骤、计时、提示和计分状态是否全部恢复。
- 每个错误只上报一次，避免在 Update/OnTriggerStay 每帧重复上报。
- 切换场景前先提交并执行决定，避免提前销毁控制器。
- 在 PICO 上检查暂停、恢复、退出与本地写入。数据只在尝试结束或组件停用时落盘；强制杀进程/崩溃可能丢失正在进行的尝试，本版不提供断点恢复。

## 文件结构

- `Runtime/Core`：纯 C# 数据、规则和有上限的单人训练会话。
- `Runtime/Unity`：Unity 控制器、规则资产、日志存储、教师展示。
- `Demo`：模拟任务、已配置场景、预制体和演示规则。
- `Editor`：打开演示、检查接入、隔离工程构建工具。
- `Documentation`：本说明、接入指南、AI 交接提示。

本包不修改 Study 1、Study 2 或任何已有项目内容；它与当前 VR 实验工程的条件、排名任务及指标无关。

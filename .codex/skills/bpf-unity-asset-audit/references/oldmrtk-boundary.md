# OldMRTK Boundary

OldMRTK assets can be used as provenance, source models, prompt/audio references, or migration material.

Do not copy or revive:

- multiplayer carriers
- Mirror networking scripts
- SycObj runtime wrappers
- LoadSceneObj legacy flow
- legacy-only scene managers

When user explicitly targets OldMRTK, audit it on its own terms and report that it is not current TexCore proof.

# Module Migration Checklist

1. Identify source legacy module.
2. Identify current business module.
3. Inventory assets by type.
4. Separate reusable assets from legacy runtime carriers.
5. Create current Prefab or scene objects in current ownership path.
6. Bind TexCore step tree.
7. Validate with Unity MCP or deterministic serialized checks.
8. Update docs only with verified mappings.
